# Kickoff and scoping

**When:** 2026-10-06 19:47 (UTC+3)

## What was asked

> “I want to go into system architecture … make something that is fully Azure, a GOVERNMENT system … ask so many questions until I tell you that I am satisfied.”

## What we did

- Ran several rounds of questions to pin down the project: a fictional GCC-style unified e-services portal called **Sahl (سهل)**, built with Laravel and React on Azure.
- Agreed it is a **career/portfolio project**, fully fictional (no real government names, logos or systems), and "design plus a full PoC — go all out".
- Picked the scenario: modelled on Qatar, with the PoC hosted in **Germany West Central (Frankfurt)** and production "on paper" in Qatar Central.
- Picked the entities: Ministry of Interior, Ministry of Municipality, Ministry of Commerce and a central Digital Government Authority.
- Saved the scope and the teaching style to Claude's memory so later sessions keep them.

## Decisions

| Decision | Choice |
|---|---|
| Purpose | Learn system architecture on Azure; portfolio piece |
| Region | PoC in Frankfurt; residency exception recorded (ADR-001) |
| Backend | Laravel modular monolith + Azure Functions satellites |
| Working style | Explain → you decide (with a recommendation) → ADR → build |
