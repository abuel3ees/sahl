# Azure services catalogue + setup playbook

**When:** 2026-10-11 02:33 (UTC+3)

## What was asked

> “Write two guides: one about all the components of Azure and which we will use and won't; the other about setting up a web app — what steps, in what order … explain everything like I know nothing.”

## What we did

- **Services catalogue:** about 100 Azure services in 17 categories, each marked ✅ used, 🏛 gov profile only, ❓ open, 📄 documented only, or ❌ not used, with a reason.
- **Setup playbook:** 22 steps in dependency order, from account and MFA through budget, policy, identity, network, data, compute, edge, monitoring, backups and go-live, plus Day-2 operations.
- Linked both from a "Companion documents" table in the architecture guide.
